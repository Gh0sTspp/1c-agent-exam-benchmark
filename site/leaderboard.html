Баллы заявлены участниками; контрольные суммы подтверждают целостность пакета, а не правильность оценки — организаторы пересчитывают результаты централизованно. «Не выше» — верхняя граница, когда часть пунктов не проверена; такие строки не получают места. Стоимость — условная оценка по стандартным тарифам API на 27.10.2026, а не счёт за подписку. Вход включает запись кеша, кеш — повторный вход. Для Claude известная запись кеша учитывается по тарифу на 5 минут; если она неизвестна, сумма может быть занижена. Длинный контекст и дополнительные услуги не учтены.
